Quick Start

1
Install Osintgram git clone https://github.com/Datalux/Osintgram && cd Osintgram
2
Start the server pip install -r requirements.txt && uvicorn src.web.app:app --host 0.0.0.0 --port 8000
3
Connect from this interface Enter your server URL above and click Connect
